FILOSOFÍA DUAL

Filosofía de Doble Modo: Seguro vs Inseguro

El proyecto tiene un "interruptor" para cambiar entre dos modos de la API en tiempo real y enseñar las vulnerabilidades.

Modo Inseguro

Sin filtros. Usa cifrado débil, y permite inyecciones SQL.

Modo Seguro

Bloquea los ataques. Usa contraseñas seguras y limita las peticiones por segundo.

FASE OFENSIVA

Sofia Audit CLI: Ataques a Nivel de Protocolo

Framework Python 3

Script en Python que hice para atacar el servidor directamente desde la terminal. Nos sirve para lanzar inyecciones o probar fuerza bruta muy rápido.

También sirve para hacer ataques de saturación (DoS). Envía muchísimas peticiones seguidas hasta que el servidor se bloquea y la página se cae.

$ python3 sofia-audit.py --attack dos --target /api/auth
