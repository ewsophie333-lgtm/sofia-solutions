FILOSOFÍA DUAL

Modo Seguro vs Modo Inseguro

El core del proyecto es enseñar qué pasa si no configuramos bien un servidor web.

Modo Inseguro

Sin barreras. Usa cifrados obsoletos (MD5) y confía ciegamente en lo que envía el usuario, permitiendo inyecciones en la base de datos.

Modo Seguro

Filtra y bloquea. Aplica algoritmos de alto coste computacional (Bcrypt) y utiliza parámetros seguros en Prisma ORM.

FASE DEFENSIVA

Prevención de Inyecciones: Web Application Firewall

Seguridad Dinámica en Node.js

Para defendernos, implementé un Middleware especial en el servidor. Todas las peticiones pasan primero por él.

Escanea los datos buscando comandos sospechosos (Expresiones Regulares). Si detecta un intento de robo o manipulación, corta la conexión de inmediato y levanta una alerta SOC.

// WAF Activo
const sqliRegex = /(UNION|SELECT|INSERT|DROP|--)/i;

if (sqliRegex.test(req.body.payload)) {
  await enviarAlertaSOC('ALTO', ipAtacante);
  return res.status(403).json({ error: "Conexión bloqueada" });
}

FASE DEFENSIVA

La Defensa: Orígenes y Cookies

Para evitar estas fugas de credenciales, el Modo Seguro de Sofia Solutions aplica varias capas de blindaje invisible para el usuario, pero infranqueable para las webs piratas.

  • Controles CORS: Sólo nuestras direcciones oficiales pueden hablar con la API.
  • Validación estricta (TargetOrigin): Impedimos que mensajes inter-ventanas viajen a dominios desconocidos.
// Mitigación en el Frontend
window.addEventListener("message", (e) => {
  // Sólo confiamos en la plataforma oficial
  if (e.origin !== "http://sofia-solutions.com") {
    return console.error("Origen no autorizado");
  }
  procesarLogin();
});

FASE DEFENSIVA

Protección de Disponibilidad (Rate Limiting)

Protección Activa en Modo Seguro

Para evitar que nos tiren el servicio, implementé una barrera de cuotas en Node.js.

  • Registra la IP de quien hace la petición.
  • Si supera las 10 peticiones por segundo, la bloquea de raíz durante 15 minutos.
  • El servidor se mantiene rápido y fluido para el resto.
// Control de Tráfico
const limitador = rateLimit({
  windowMs: 1 * 60 * 1000, // 1 minuto
  max: 30, // 30 peticiones tope
  message: "Demasiadas peticiones. Intente más tarde"
});

OBSERVABILIDAD

El Motor de Telemetría: Prometheus

¿Cómo recolectamos los datos de los ataques? Usamos Prometheus, un software estándar en la industria.

  • Nuestro servidor web expone un informe métrico interno cada segundo.
  • Prometheus recopila ese archivo y almacena la información como una base de datos cronológica.
# HELP http_requests_total Número de peticiones
# TYPE http_requests_total counter
http_requests_total{method="POST",route="/api/login",status="403"} 52
http_requests_total{method="GET",route="/consola",status="200"} 15

# HELP soc_alerts_total Alertas generadas por el WAF
soc_alerts_total{severity="CRITICAL"} 2
