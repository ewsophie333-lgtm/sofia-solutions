Prevención: Web Application Firewall (WAF)

Seguridad Dinámica en Backend

¿Cómo mitigamos peticiones que vienen alteradas por un Proxy? En el Modo Seguro, un middleware especial escanea todas las entradas antes de que toquen la base de datos.

Usa Expresiones Regulares para cazar comandos SQL maliciosos o etiquetas XSS. Si hay positivo, aborta la petición y dispara una alerta.

// WAF Activo middleware.ts
const sqliRegex = /(UNION|SELECT|INSERT|DROP|--)/i;

if (sqliRegex.test(req.body.payload)) {
  await notificarSOC('ALTO', ipAtacante);
  return res.status(403).json({ error: "Conexión bloqueada" });
}

Mitigación de Phishing (CORS y Origins)

¿Cómo cerramos esta fuga en el Modo Seguro? Restringiendo estrictamente quién puede hablar con quién a nivel de navegador y servidor.

  • CORS Estricto: Solo el dominio oficial puede consultar la API.
  • TargetOrigin: Rechazamos cualquier mensaje entrante de `window.postMessage` cuyo origen no sea exactamente nuestra URL autorizada.
// Bloqueo de comunicaciones cruzadas
window.addEventListener("message", (e) => {
  // Autorización por dominio explícito
  if (e.origin !== "http://sofia-solutions.com") {
    return console.warn("Violación de Origen Detectada");
  }
  procesarTokenSesion();
});

FASE DEFENSIVA

Protección de Disponibilidad (Rate Limiting)

Defensa Activa en Modo Seguro

Implementé un middleware limitador de tráfico para prevenir estas caídas.

  • Asigna una cuota máxima de peticiones por segundo a cada IP.
  • Si el atacante sobrepasa la cuota, es baneado temporalmente devolviendo un código `429 Too Many Requests`, salvando el servidor.
// Control de Tráfico Middleware
const limitador = rateLimit({
  windowMs: 15 * 60 * 1000, // Ventana de 15 minutos
  max: 100, // 100 peticiones tope por IP
  message: "Límite excedido. Intente más tarde"
});
app.use('/api/', limitador);

Extracción de Telemetría: Prometheus

¿Cómo recolectamos los datos de los ataques? Usando Prometheus, la herramienta estándar de extracción de métricas.

  • Node.js expone métricas contínuas en el endpoint `/metrics`.
  • Prometheus recopila ese texto plano (Scraping) periódicamente y almacena la información como una serie temporal de datos.
