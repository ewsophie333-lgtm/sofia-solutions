Objetivos del Proyecto

Hacer que conceptos abstractos como SQLi o Phishing sean fáciles de entender al ver el ataque y la defensa en tiempo real.

FILOSOFÍA DUAL

El Interruptor de Seguridad: API Dual

Desarrollé un sistema que permite cambiar el nivel de seguridad de la aplicación con un solo clic. Ideal para hacer demostraciones de qué ocurre si no programamos con cuidado.

Modo Vulnerable

Sin controles. Acepta contraseñas débiles y peticiones maliciosas directamente a la base de datos.

Modo Seguro

Filtra y bloquea. Aplica algoritmos fuertes (Bcrypt) y bloquea intentos repetidos.
