🏗️ Arquitectura de Referencia (Defensa en Profundidad)

La plataforma Sofia Solutions implementa un modelo de Defensa en Profundidad perimetral y lógica estructurado en cuatro niveles fundamentales. Esto garantiza que ante el compromiso de una capa superior, las subyacentes mantengan protegidos los activos críticos:

1. Capa Perimetral L7

Mapeo de puertos seguro, túneles con cifrado SSL robusto de Serveo y balanceo inverso en Apache.

2. Capa de Aplicación

Web Application Firewall (WAF) programado en TypeScript, validación de schemas con Zod y control de tasas (Rate Limiting).

3. Capa de Almacenamiento

Base de datos relacional PostgreSQL 15, aislamiento estricto multi-tenant y Prepared Statements a través de Prisma ORM.

4. Capa de Monitoreo (SOC)

Colector de métricas Prometheus, contenedores cAdvisor para telemetría de hardware y visualización en Grafana.

🛡️ Mecanismos de Seguridad Lógica y Criptografía

1. Web Application Firewall (WAF) a nivel de Middleware

He desarrollado un motor WAF heurístico desde cero integrado como middleware en Express. Este intercepta todas las solicitudes entrantes y analiza los parámetros en la ruta, las queries de consulta y el cuerpo en JSON contra patrones de expresiones regulares:

2. Criptografía y Hashing de Credenciales

En el Modo Vulnerable, las contraseñas se almacenan empleando hash MD5 sin sal (salt), lo cual las hace vulnerables a ataques de diccionario rápidos y tablas arcoíris.

En el Modo Seguro, el sistema implementa la librería bcryptjs empleando un factor de costo (salt rounds) de 12 rondas. Esto añade retardos computacionales deliberados y genera hashes salados únicos para cada usuario, imposibilitando la precomputación de contraseñas.

3. Gestión de Sesión y Seguridad JWT

Las cookies de sesión en el modo seguro se firman digitalmente y se protegen mediante directivas estrictas en las cabeceras HTTP:

  • HttpOnly: Evita que scripts del lado del cliente (ataques XSS) puedan acceder a las cookies.
  • Secure: Fuerza a que la cookie solo viaje a través de conexiones HTTPS cifradas.
  • SameSite=Strict: Previene ataques de falsificación de petición en sitios cruzados (CSRF).

📊 Observabilidad SOC e Integración SOAR

Correlación de Eventos en Tiempo Real:

Cuando el WAF intercepta un ataque o el Rate Limiter bloquea un intento fallido, el sistema realiza tres acciones en paralelo: incrementa un contador en Prometheus, registra el evento geolocalizado en la tabla Incidente y dispara un Webhook automatizado en n8n.

Orquestación Automática con n8n

El flujo de n8n recibe el payload HTTP del backend, realiza una clasificación basada en la severidad (urgencia) del incidente y, si califica como crítico (SQLi o Rootkit), envía un correo electrónico SMTP enriquecido al analista del SOC con el siguiente formato estructurado:
